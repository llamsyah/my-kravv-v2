# V3 design workspace

Status: **Owner-approved direction; specifications pending.** Recorded 17 October 2026 (Asia/Jakarta) from the owner's repository reorganization brief. No application changes or new mockups are authorized by this document.

The owner selected **Hybrid C**: modern, premium SaaS quality; clean, organized and calm for long-form thinking; strong information architecture with little visual noise; light-first with thoughtfully designed dark mode; neutral reading surfaces and restrained green accents. Typography, spacing, actions and interaction patterns should be consistent. Exact fonts, spacing and color tokens are not specified by an illustration.

## Approved structural direction

- Global top navigation: Beranda and Perusahaan are main destinations; search, theme and account utilities can be separate.
- Company Workspace: contextual collapsible left sidebar, with Overview, Pemikiran, Explore and Referensi as current conceptual areas. Company switching must scale without permanently listing every company in a rail. Keep reading/writing width controlled when the sidebar collapses and tools discoverable without clutter.
- Home: Quick Capture is the primary focal point within a calm hero. Continue/resume, recent captures, contextual review and company access are secondary. Quick Capture is a mutable collection area, not an automatic immutable Thought commit. This is a V3 direction, not a description of current V2 capture behavior.
